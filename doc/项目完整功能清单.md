# 智能答题卡批改系统 - 项目完整功能清单

## 1. 系统定位与形态
- 面向学校、培训机构、考试场景的桌面端智能阅卷系统。
- 支持单机离线使用（本地识别、本地配置、本地导出）。
- 支持打包为 Windows 可执行程序（PyInstaller）。
- 提供试用与激活授权机制，支持商用部署。

## 2. 界面与导航能力
- 左侧导航分区：`阅卷中心`、`阅卷痕迹`、`阅卷报告`、`数据统计`、`参数设置`。
- 主区域多页面切换，支持“配置-阅卷-复核-统计”完整闭环。
- 右侧智能助手面板可显示/隐藏，支持常驻操作。
- 阅卷配置开关具备 `ON/OFF` 状态标识，避免歧义。

## 3. 输入与任务模式
- 支持单文件阅卷（单张答题卡处理）。
- 支持批量阅卷（按文件夹批处理）。
- 支持常见图片格式：`jpg`、`jpeg`、`png`。
- 支持实时进度反馈、状态日志显示、处理阶段提示。

## 4. 客观题识别与评分
- 基于 OMR 流程完成客观题识别。
- 支持识别模式配置（A/B 模式）。
- 支持题列布局配置（`row`/`column`）与题组大小配置。
- 支持按配置文件读取标准答案、分值、选项数量。
- 支持单选题/多选题识别与评分。
- 支持客观题评分规则配置（标准评分、部分扣分等策略）。

## 5. 主观题 AI 辅助阅卷
- 支持主观题标准答案文件配置与加载。
- 支持主观题题号、分值、参考答案、提示词配置。
- 支持多模态大模型接口配置（API Key、Base URL、模型名称）。
- 支持主观题评分报告生成与归档。
- 支持主观题功能开关，按需启用。

## 6. 学生信息与条形码识别
- 支持学生信息识别开关（姓名/学号相关信息）。
- 支持条形码识别开关。
- 条形码识别结果可写入学号/准考证号字段。
- 条形码识别支持 OpenCV 与 pyzbar 双路径识别。
- 条形码识别支持“纠偏图失败 -> 原图回退识别”策略。

## 7. AI Agent 对话式配置（新功能）
- 支持通过智能助手对话生成客观题配置。
- 支持通过智能助手对话生成主观题配置。
- 支持上传试卷图片辅助解析配置内容。
- 支持“一键应用客观题配置/主观题配置”到系统。
- 支持配置应用后即时生效。

## 8. 阅卷痕迹、报告与联动预览
- 自动保存阅卷痕迹文件（original / annotated / records / summary）。
- 自动保存主观题及综合报告文件。
- 支持“结果表 -> 痕迹/报告文件”联动。
- 支持文本预览与图片预览双模式切换。
- 匹配不到目标文件时支持回退展示，避免空白区。

## 9. 统计与文件管理能力
- 支持 `read` / `reports` 目录统计。
- 支持统计卡片（数量、体积等摘要信息）。
- 支持表格化文件清单（名称、大小、时间、路径）。
- 支持点击即预览文件内容（文本/图片）。
- 支持痕迹页和报告页独立管理。

## 10. 配置管理与路径策略
- 可视化系统配置：答案配置、主观题配置、模型与 API 配置。
- 支持配置保存、加载、回填与持久化。
- 支持相对路径策略（`config\answer_config\...`），提升跨电脑可移植性。
- 兼容旧配置路径与旧文件名自动回退映射。
- 支持开发环境与打包环境路径自适配。

## 11. 结果输出与数据导出
- 支持成绩结果表展示：学号、姓名、客观题成绩、主观题成绩、总分。
- 支持单次处理与批量处理结果汇总。
- 支持导出成绩数据（CSV/Excel 方向）。
- 支持批处理结束后自动刷新统计与结果展示。

## 12. 稳定性与容错机制
- 核心识别流程异常降级，避免批处理中断。
- 关键路径支持文件不存在回退策略。
- 防止 `NoneType` 解包类异常导致任务失败。
- 配置与识别流程包含可追踪日志输出。
- 打包已处理 pyzbar 动态库依赖收集问题。

## 13. 授权与商用能力
- 支持试用状态（trial）与激活状态（activated）管理。
- 支持激活码校验与激活流程。
- 支持授权状态持久化、过期和异常状态检测。

## 14. 可扩展能力
- 配套授权服务端模块（`auth_serve`）可用于后续商用接入。
- 核心模块分层清晰（OMR、主观题、配置管理、路径管理、导出管理）。
- 支持模型与接口替换，便于后续接入私有化模型或其他服务。
